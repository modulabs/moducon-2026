# MODUCON 2025 · JavaScript 프론트엔드

https://moducon.modulabs.co.kr/ 홈페이지를 HTML, CSS, 순수 JavaScript로 재현한 프로젝트입니다. 별도 프레임워크와 패키지 설치가 필요 없습니다.

## 실행

`dist/index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면 이 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 4173 --directory dist
```

그다음 http://localhost:4173 에 접속하세요.

## 파일 안내

- `dist/index.html`: 홈페이지 콘텐츠와 반응형 화면 구조
- `dist/reference.css`: 원본에서 보존한 레이아웃, 폰트, 화면 크기별 스타일
- `dist/styles.css`: 메뉴, FAQ, 접근성 등 추가 스타일
- `dist/app.js`: 모바일 메뉴, 카드 슬라이드, FAQ, 공유 기능
- `dist/assets/`: 로컬 이미지와 폰트
- `asset-sources.json`: 원본 자산의 출처

## 구현 범위

메인 비주얼, 행사 소개, 6개 메인 트랙, 키노트와 트랙별 세션 카드, 장소 안내, FAQ 7개, 공유 배너, 파트너 로고, 푸터를 재현했습니다. 원본의 데스크톱·태블릿·모바일 스타일과 이미지를 보존하고 동작은 순수 JavaScript로 다시 구현했습니다. 메뉴 닫기와 FAQ는 키보드로도 동작하며, 카드 영역은 스와이프와 방향키를 지원합니다.

홈페이지 상단 전체세션·FAQ는 해당 섹션으로 이동합니다. 개별 발표 상세 페이지, YouTube 다시보기, 신청·알림 폼과 지도는 원본 외부 링크를 사용합니다. 별도 상세 페이지나 신청 백엔드는 포함하지 않습니다. 공유하기는 공식 홈페이지 링크를 공유합니다.

원본의 Framer 실행 코드와 Google/Meta/Framer 추적 코드는 포함하지 않았습니다. 정적 화면은 JavaScript 없이도 보이며, FAQ 답변은 JavaScript 실행 시 접힌 상태로 전환됩니다.

행사 정보는 2026년 9월 9일 확인한 원본의 **MODUCON 2025** 내용을 보존했습니다. 디자인·브랜드·이미지·폰트의 권리는 원권리자에게 있습니다.

## 확인 범위

JavaScript 문법, 로컬 이미지·폰트 경로, 섹션 링크, FAQ 데이터, 추적 코드 제거 및 HTTP 응답을 확인했습니다. 브라우저 자동화나 원본과의 픽셀 비교는 수행하지 않았습니다.
