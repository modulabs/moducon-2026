# MODUCON 2025 · JavaScript 프론트엔드

https://moducon.modulabs.co.kr/ 의 홈페이지와 공개 하위페이지 전체를 HTML, CSS, 순수 JavaScript로 재현한 프로젝트입니다. 별도 프레임워크와 패키지 설치가 필요 없습니다.

## 실행

`dist/index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면 이 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 4173 --directory dist
```

그다음 http://localhost:4173 에 접속하세요.

## 파일 안내

- `dist/index.html`: 홈페이지
- `dist/session/index.html`: 전체 세션 시간표
- `dist/session/*/index.html`: 세션 상세 46개
- `dist/faq/index.html`: FAQ
- `dist/archive_241114/index.html`: 아카이브
- `dist/page/index.html`: 원본 사이트맵에 공개된 추가 페이지
- `dist/page-styles/`: 원본 레이아웃과 반응형 스타일 6종
- `dist/styles.css`: 메뉴, FAQ, 접근성 등 공통 추가 스타일
- `dist/app.js`: 내부 이동, 모바일 메뉴, 슬라이드, FAQ, 영상, 로고 흐름, 공유 기능
- `dist/assets/`: 로컬 이미지·폰트·영상 198개
- `asset-sources.json`: 원본 자산의 출처
- `routes.json`: 전체 51개 경로, 제목, 파일 위치, 원본 주소

## 구현 범위

원본의 사이트맵 및 내부 링크에서 확인한 총 51개 페이지를 포함합니다. 홈페이지 외에 현재 세션 상세 31개, 아카이브에서 연결되는 이전 세션 상세 15개, 전체 세션 시간표, FAQ, 아카이브, 추가 공개 페이지를 재현했습니다. 세션 제목·시간·장소·설명·연사 소개·이미지를 각 원본에서 가져왔습니다.

원본의 데스크톱·태블릿·모바일 스타일을 보존하고 동작은 순수 JavaScript로 다시 구현했습니다. 메뉴와 FAQ는 키보드로도 동작하며, 카드 영역은 스와이프와 방향키를 지원합니다. 아카이브 영상은 화면에 보일 때만 자동 재생되고, 사용자가 움직임 줄이기를 설정하면 정지합니다.

모든 내부 메뉴와 세션 카드는 복사본 안에서 이동합니다. 웹서버에서는 `/session/00-00/` 같은 경로로 이동하며, 파일을 직접 열면 상대 경로의 `index.html`을 사용합니다. 각 하위페이지를 직접 열거나 새로고침할 수 있습니다.

YouTube 다시보기, 신청·알림 폼과 지도는 원본 외부 링크를 사용합니다. 외부 서비스의 백엔드는 포함하지 않습니다. 공유하기는 공식 홈페이지 링크를 공유합니다.

원본의 Framer 실행 코드와 Google/Meta/Framer 추적 코드는 포함하지 않았습니다. 정적 화면은 JavaScript 없이도 보이며, FAQ 답변은 JavaScript 실행 시 접힌 상태로 전환됩니다.

행사 정보는 2026년 9월 9일 확인한 원본의 내용입니다. 아카이브의 이전 행사 정보와 원본의 표기를 함께 보존했습니다. 디자인·브랜드·이미지·폰트·영상의 권리는 원권리자에게 있습니다.

## 확인 범위

JavaScript 문법, 51개 페이지의 HTML 구조, 원본 내부 링크 보존, 모든 로컬 링크와 이미지·폰트·영상 경로, 섹션 링크, FAQ 데이터, 추적 코드 제거 및 각 페이지의 HTTP 응답을 확인했습니다. 브라우저 자동화나 원본과의 픽셀 비교는 수행하지 않았습니다.
