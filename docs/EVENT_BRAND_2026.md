## 후원사

Clabi, Kakao!mpact, Tenstorrent 로고를 현재 홈페이지 후원 영역에서 제거하고, 사용자 제공 `Rebellions_Logo.svg`와 `hyperaccel_logo.png`를 원본 그대로 추가했습니다. 나머지 기관 로고는 유지했습니다. 로고 파일은 `dist/assets/sponsors-2026/`에 있습니다.

현재 후원 순서는 Rebellions → HyperAccel → kakao → 고용노동부 → 한국산업인력공단 → K-하이테크 플랫폼입니다. kakao는 새로 제공받은 노란색 로고를 사용하며, 이전 Kakao!mpact와 구분합니다. 주관은 모두의연구소와 이화여자대학교 창업지원단이며, AIX 사업단 표기는 주관 영역과 홈페이지 푸터에서 제거했습니다.

로고 원본 파일은 수정하지 않습니다. `home-logo-artwork`의 표시 영역으로 원본의 빈 여백만 제외하고, `--logo-width`로 실제 글자·심볼의 크기를 맞춥니다. 이미지 가로세로 비율과 색상은 유지하며, 이화여대와 카카오처럼 여백이 큰 새 파일로 교체할 때는 표시 영역 값도 함께 확인해야 합니다.
