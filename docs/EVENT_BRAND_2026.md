## 후원사

Clabi, Kakao!mpact, Tenstorrent 로고를 현재 홈페이지 후원 영역에서 제거하고, 사용자 제공 `Rebellions_Logo.svg`와 `hyperaccel_logo.png`를 원본 그대로 추가했습니다. 나머지 기관 로고는 유지했습니다. 로고 파일은 `dist/assets/sponsors-2026/`에 있습니다.

현재 주관은 모두의연구소와 이화여자대학교 창업지원단입니다. 연구개발 협력기관은 Rebellions와 HyperAccel로, 행사 후원과 별도 표시합니다. 모두의연구소가 두 기업이 각각 주관하는 연구개발과제의 성과확산 활동으로 행사를 수행하는 관계를 반영했습니다. 후원 순서는 kakao → 고용노동부 → 한국산업인력공단 → K-하이테크 플랫폼입니다. kakao는 새로 제공받은 노란색 로고를 사용하며, 이전 Kakao!mpact와 구분합니다. AIX 사업단 표기는 주관 영역과 홈페이지 푸터에서 제거했습니다.

홈페이지 하단에 `연구개발과제 지원 및 사사`를 추가했습니다. 행사를 연구 결과물로 단정하지 않고, 정부(과학기술정보통신부)의 재원과 정보통신기획평가원(IITP)의 지원을 받아 수행 중인 두 과제의 성과를 공유·확산하는 행사로 설명합니다. 기존 K-Hightech Platform 사업 지원 안내는 유지합니다.

과제번호 `RS-2026-25521385`, `RS-2025-02304125`의 사업명·국영문 과제명·기간·참여기관은 사용자가 제공한 내용을 기준으로 반영했습니다. 주관·공동·위탁연구개발기관을 각 과제 안에서 구분합니다. 두 번째 영문 과제명의 `Al` 표기는 제공된 원문을 유지했으며, 공식 영문명 확인 후에만 변경합니다. 과제번호와 연구개발 시작일의 2025는 실제 과제 정보이므로 현재 행사 연도로 치환하지 않습니다. 이 문구를 협약서와 대조한 공식 지정 사사라고 보증하지 않습니다.

로고 원본 파일은 수정하지 않습니다. `home-logo-artwork`의 표시 영역으로 원본의 빈 여백만 제외하고, `--logo-width`로 실제 글자·심볼의 크기를 맞춥니다. 이미지 가로세로 비율과 색상은 유지하며, 이화여대와 카카오처럼 여백이 큰 새 파일로 교체할 때는 표시 영역 값도 함께 확인해야 합니다.
