# 모티프 적용 시안

첨부된 Motif_Modulabs.ttf를 그대로 포함한 로컬 HTML 시안입니다. 라이브 사이트에는 반영하지 않았습니다.

- 메인 제목 ‘모두콘’: 같은 크기와 기준선에서 모=500, 두=530, 콘=620의 실제 wght 축 적용. 글자의 세로·가로 비율을 별도로 늘리지 않습니다.
- 연도 ‘2026’: 숫자열의 음절별 가변 규칙은 공식 가이드에 명시되어 있지 않아 기본값 500으로 유지합니다.
- 모티프는 제목에 사용하며, 긴 설명·메뉴·버튼·일정·푸터는 일반 본문 글꼴로 구분합니다.
- 공식 이미지의 자간 -35는 단위가 표시되어 있지 않습니다. 이 웹 시안은 디자인 툴의 tracking -35로 해석해 -0.035em을 적용했습니다. 이는 공식 CSS 명시값이 아닌 구현 해석입니다.
- 아이보리·코발트블루 팔레트와 블록 그림은 이번 디자인 제안이며, 모티프 공식 지정 색상·그래픽으로 주장하지 않습니다.
- 행사 슬로건은 시안용 문구이며 날짜와 장소는 미정 표시입니다.
- PNG와 PDF는 이 HTML을 실제 브라우저로 렌더링한 출력입니다.
