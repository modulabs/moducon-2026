- 보관일: 2026년 10월 24일 (한국 시간)
- 원본 주소: https://moducon.modulabs.co.kr/session/
- 원본 Sites 저장소 커밋: `f8886a618104d25e230cf2d59402be4f54b0ef41`
- 세션 페이지: 목록 1개와 상세 46개, 총 47개
- 원본 파일: 필요한 스타일·동작·이미지·글꼴을 포함한 114개, 24,248,653바이트
- 2026년 세션 페이지는 이 폴더에 포함하지 않았습니다.

이 폴더는 GitHub에 보관하는 자료입니다. 현재 사이트에 게시하는 `dist/` 밖에 있으므로 `2025/`의 내용이 자동으로 사이트에 공개되지는 않습니다. 원본의 잘못된 표기나 오래된 링크도 역사 자료를 보존하기 위해 임의로 고치지 않았습니다.

## 파일 찾기

- `session/index.html`: 기존 2025 세션 목록
- `session/<기존 세션 코드>/index.html`: 기존 세션 상세
- `assets/`, `page-styles/`, `styles.css`, `app.js`: 세션 화면이 사용하는 원본 자료
- `routes.json`: 보관한 세션 경로 목록
- `manifest.json`: 원본 경로·파일 크기·SHA-256 해시와 링크 점검 기록
- `verify_archive.py`: 원본 파일이 누락되거나 변경되었는지 확인하는 도구
- `index.html`, `faq/index.html`: 보관본을 설명하는 새 안내 페이지. 2025 당시의 홈페이지나 FAQ를 복원한 것은 아닙니다.

## 화면 열어보기

Python이 설치된 컴퓨터에서 GitHub 저장소를 내려받고 저장소 폴더에서 다음을 실행합니다.

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory 2025
```

그다음 브라우저에서 http://127.0.0.1:4173/session/ 을 엽니다. 종료하려면 실행한 창에서 `Ctrl+C`를 누릅니다.

반드시 `2025` 폴더 자체를 서버의 시작 폴더로 사용하세요. 원본 JavaScript는 세션 링크를 `/session/.../` 형태로 바꾸므로 저장소 전체를 서버로 열면 다른 폴더의 페이지로 이동할 수 있습니다. 인터넷으로 연결되는 당시 다시보기 링크는 원래 주소가 유지됩니다.

## 보관 상태 확인

저장소 폴더에서 다음을 실행하면 원본 114개 파일을 보관 당시 해시와 비교합니다.

```sh

```

`OK`가 나오면 누락되거나 바뀐 원본 파일이 없는 상태입니다. 보관 당시 HTML·CSS에서 참조하는 로컬 자료 588건을 확인했으며 누락은 없었습니다. Home·FAQ 메뉴는 이 보관본의 안내 페이지로 이어집니다.
